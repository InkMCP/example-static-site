# Example Static Site

A simple HTML/CSS/JS static site, ready to deploy.

## Setup

Open `index.html` in your browser. No build step needed.

## Deploy with Ink

Connect the [Ink MCP server](https://docs.deployink.com/quick-start) to your AI agent and prompt:

> Deploy this static site with Ink.

Full tutorial: [docs.deployink.com/examples/frontend/static-site](https://docs.deployink.com/examples/frontend/static-site)
